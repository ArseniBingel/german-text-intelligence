# german-text-intelligence

Two German-language NLP pipelines built with scikit-learn: topic classification
of news articles, and rule-based field extraction from maintenance reports.

Both pipelines are built end to end, measured per class and per input type, and
the errors are analysed rather than just counted.

## Results

### Topic classification (10kGNAD, 9 classes, 10,271 articles)

| Model | Accuracy | Macro-F1 |
|---|---|---|
| Majority class (floor) | 0.163 | 0.031 |
| TF-IDF + LogisticRegression | 0.834 | 0.825 |
| Sentence embeddings + LogisticRegression | 0.793 | 0.780 |

5-fold cross-validated macro-F1 on the training split: 0.812 ± 0.007. The spread is the size of difference between two models that could come from the split alone.

### Field extraction (200 synthetic maintenance reports, 7 fields)

| Report style | Accuracy |
|---|---|
| Labelled fields | 1.000 |
| Inconsistent formatting | 0.977 |
| Freetext, no labels | 0.822 |
| **Overall** | **0.957** |

Two fields carry the whole loss: `technician` 0.795 and `downtime_minutes`
0.905. The other five score 1.000.

## Findings

**Raw word frequency carries no topic signal.** The twenty most frequent tokens
are the same for all nine classes: die, der, und, in, das. That is what the IDF
weighting in TF-IDF corrects for.

**Pruning removed three quarters of the vocabulary at no cost.** The raw corpus
has 189,235 distinct tokens, about 45,000 after dropping anything that appears
in fewer than three documents. The dropped tokens are mostly names, numbers and
typos.

**Etat fails with high precision and low recall.** Etat is Austrian media
industry coverage. The model rarely labels something Etat wrongly but misses a
large share of the real ones. The vocabulary overlaps with Wirtschaft, because
an article about a broadcaster's finances reads like a business article.

**Panorama collects errors from every other class.** It is the miscellaneous
section of the newspaper and has no vocabulary of its own. This is a property of
the labelling scheme, not of the model.

**Regex handles structure, not language.** Extraction is perfect on labelled
reports and 18 points lower on freetext. Nearly all of the gap is `technician`,
which freetext writes as "Rückmeldung durch T. Brandt" with no label to anchor a
pattern to. Rules first with an LLM fallback would cover both cases at a
fraction of the API calls of sending every document to a model.

**Validation is in one place.** An earlier version of `extract.py` checked field
formats twice, once in a Pydantic schema and once by hand. The two drifted apart:
the manual check had no upper bound on downtime, so a misread unit giving 99,999
minutes passed. The schema is now the only definition.

## Repo layout

```
src/
  data.py         download, parse and clean the 10kGNAD corpus
  explore.py      class distribution, document lengths, token statistics
  features.py     stratified splits, TF-IDF baseline, scoring
  eval.py         per-class metrics, confusion matrix, error analysis, CV
  embeddings.py   sentence embeddings with a disk cache
  reports.py      synthetic German maintenance reports with known ground truth
  extract.py      regex extraction, Pydantic validation, per-field scoring
```

Every module runs standalone and checks its own output:

```bash
python src/data.py
python src/explore.py
python src/features.py
python src/eval.py
python src/embeddings.py
python src/reports.py
python src/extract.py
```

## Setup

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python src/data.py               # downloads the corpus (27 MB)
```

`src/embeddings.py` downloads a 470 MB model on the first run and takes several
minutes to encode the corpus on CPU. The vectors are cached in `data/`.

## Data

**10kGNAD** — 10,273 German news articles from Der Standard in 9 topic
categories, from [tblock/10kGNAD](https://github.com/tblock/10kGNAD). Fetched by
`data.py` and not committed.

The file is a headerless semicolon-separated CSV. German prose contains many
semicolons, so pandas' default settings raise a `ParserError` on line 3. Field
boundaries are marked with single quotes instead of the usual double quotes.

**Maintenance reports** — generated by `reports.py`. That gives exact ground truth
without annotation. Three styles: labelled fields, inconsistent formatting, and
prose without labels.

## Known limitations

**The synthetic corpus only contains the messiness it was written to contain.**
Real documents fail in other ways, so these scores are not an estimate of
real-world performance.

**Downtime scores 0.905 because of the generator, not the extractor.** Hours are
written with one decimal, so 45 minutes becomes "0,8 Stunden" and reads back as
48. The information is lost before extraction runs.

**`parse_downtime` takes the first duration in the text.** Dropping the label
requirement is what makes freetext work, but a report with two durations would
give the wrong one and raise nothing.

**Deduplication is exact-match only.** Near-duplicate articles, such as wire
copy republished with a changed headline, would survive and could end up in both
train and validation.

**The embedding model truncates at 128 tokens.** Median article length is about
298 words, so most of each document never reaches the encoder and the vector
describes the opening paragraph.
